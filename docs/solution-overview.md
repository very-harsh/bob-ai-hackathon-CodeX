# Solution Overview

## What We Built

we built an ASSISTANT , which prioritizes the evidences found at the crime scene ON THE BASIS of urgency and time sensitivity.

## How It Works
1. The user connects to the host
2. input the evidence description , when it was collected and how was it found .
3. get the list of evidence in a prioritized and ordered structure.

## Key Design Decisions
Makes it urgent , if the evidence is required to be examined urgently. 
Makes it one day , if the evidence is required to be examined in one day. 

## IBM Technologies Used

IBM bob is integrated into the assistant , that prioritizes the evidence list . it works on a given data set which contains most of the evidences found on the crime scene.
